0 bits ≈ 20 possible guesses to search the whole space.

H = L × log₂(N)   (L = length, N = alphabet size: 26 lowercase, 26 uppercase, 10 digits, ~33 symbols)

Entropy is a measure of unpredictability: each extra bit doubles the number of guesses needed. This formula is valid only if every character is chosen independently and uniformly at random. Human-made passwords are not, so the “pattern-adjusted” figure removes characters that continue a repeat or sequence (e.g. “aaa”, “123”), and common words are scored by their rank in a small sample list. Both are teaching heuristics, not measurements. Theoretical search space is not the same as real guess difficulty, and entropy alone never guarantees safety.

      Challenge mode

      Security guide

      What is password entropy?

      A measure of how unpredictable a password is, in bits. Each bit doubles the guesses needed. It describes how the password was chosen, not just how it looks.

      Brute-force vs dictionary attacks

      Brute force tries every combination. Dictionary attacks try likely passwords first: common words, names, leaked passwords and tweaks like “P@ssw0rd”. Predictable passwords fall far sooner than the brute-force math suggests.

      Online vs offline attacks

      Online attacks guess against a live login and are slowed by rate limits and lockouts. Offline attacks start from a stolen hash database and run as fast as the attacker’s hardware allows.

      Hashing and salting

      Sites should store a slow, salted hash (e.g. Argon2id, bcrypt, scrypt), not the password. A unique random salt per user stops precomputed tables and makes each account crack separately. Slow hashes cut offline guess speed dramatically.

      Why rate limiting matters

      It caps how many guesses an attacker can make online, turning a quick attack into one that is impractical, especially with lockouts and multifactor authentication.

      Reuse and credential stuffing

      Attackers take leaked username-password pairs and try them on other services. This is not brute force: one reused password unlocks many accounts, however strong it is.

      Why long, unique passwords

      Length multiplies the search space; uniqueness contains the damage of a breach. Use a password manager with generated passwords or long random passphrases, and turn on multifactor authentication. Symbol substitutions alone do not make a predictable password secure.
